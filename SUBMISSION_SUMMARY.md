## 🎓 Key Learnings

### What Worked:
1. **arXiv API**: Reliable, no authentication, comprehensive data
2. **RSS Feeds**: Simple, real-time, no rate limits
3. **RemoteOK API**: Open, no auth, good for jobs
4. **Rate Limiting**: Essential for avoiding bans
5. **Quality First**: Better to submit real data than fake volume

### Challenges Faced:
1. **Semantic Scholar**: Immediate HTTP 429 (needs API key)
2. **Limited Free APIs**: Most startup/product APIs are paid
3. **Job Freshness**: Limited AI/ML jobs at extraction time
4. **RSS Limits**: Many feeds have only 10-50 recent articles
5. **Time Constraint**: 7 hours from start to submission

### If Starting Over:
1. Get API keys first (Semantic Scholar, Crunchbase)
2. Budget for paid APIs ($50-100)
3. Set up proxy rotation for scraping
4. Allow 2-3 days for 20k+ real records
5. Start with highest-volume sources
